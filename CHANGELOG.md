## [0.1.0] - 2026-08-10

### Added

- Opt-in `--bridge` activation for Claude Code peer messaging.
- Claude-compatible peer discovery and local Unix socket transport.
- `list_agents` and `send_message` tools for enabled Pi sessions.
- Scoped Effect 3 lifecycle management and conservative stale-record cleanup.
- Bounded peer frames and controlled failure handling.
